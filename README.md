🏎️ Dashboard Porsche

Bem-vindo(a) ao repositório do Dashboard Porsche! Este projeto é uma interface interativa (dashboard) desenvolvida para apresentar dados e informações inspiradas na marca Porsche.

🔗 Acesse o projeto ao vivo aqui

📋 Sobre o Projeto

Este projeto tem como objetivo principal criar uma experiência visual e interativa focada no universo da Porsche. O dashboard apresenta um design limpo e responsivo, ideal para visualizar métricas, modelos ou informações relevantes sobre os veículos da marca.

🚀 Como Executar o Projeto Localmente

Se desejar clonar este projeto e rodá-lo na sua própria máquina, siga os passos abaixo:

Clone o repositório:

git clone https://github.com/lucasbritoo1/Dashboard_Porsche_.git


Navegue até o diretório do projeto:

cd Dashboard_Porsche_


Abra o ficheiro principal:
Basta abrir o ficheiro index.html no seu navegador de preferência. Não é necessário instalar dependências adicionais (a não ser que esteja a usar um framework).
